# שירים גן ניצנים

אתר סטטי עם נגן השירים של הגן, מתארח ב-GitHub Pages:
**https://eranshmueli96.github.io/nitzanim/**

## מבנה

- `index.html` — כל האפליקציה (רשימה, חיפוש, מסך נגן, השמעה ברצף)
- `songs.json` — הספרייה; נוצר על ידי `build.py`, לא לערוך ביד
- `audio/` — קבצי ה-MP3
- `build.py` — מעתיק את הקבצים מ-`../שירים אחרי איחוד/` ובונה את `songs.json`
- `manifest.webmanifest` + אייקונים — "הוספה למסך הבית"

## הוספה או החלפה של שיר

1. לשים את ה-MP3 המאוחד ב-`../שירים אחרי איחוד/`
2. להוסיף שורה ל-`SONGS` ב-`build.py` (מזהה באנגלית, שם הקובץ, השם שיוצג)
3. `python3 build.py`
4. `git add -A && git commit -m "..." && git push`

העמוד מתעדכן תוך כדקה. הקישור לעולם לא משתנה.

## למה אין קידוד מחדש

הקבצים המאוחדים כבר דחוסים (80–192 kbps). קידוד מחדש הוא דחיסה על דחיסה —
פוגע באיכות בלי להרוויח כלום. `build.py` מעתיק אותם כמו שהם, ולכן אין צורך
ב-ffmpeg ובשום כלי חיצוני. GitHub Pages מגיש טווחי בתים, כך שהגלילה בתוך שיר
עובדת ישירות מהרשת בלי להוריד את הקובץ כולו.
